# Mayhem — Responsive Email

Responsive HTML email templates created for **Mississippi Valley Mayhem Roller Derby** for use in email marketing campaigns.

The templates were designed for deployment through an email service provider (ESP) such as Mailchimp, Constant Contact, or MailerLite, with an emphasis on responsive layouts and compatibility across email clients.

## Templates

### `welcome_email.html`

Sent immediately after a visitor subscribes to the newsletter. Welcomes the new subscriber, provides a promotional ticket coupon, and introduces the upcoming season.

### `tickets_email.html`

Sent a few weeks before the season begins. Provides the complete home-game schedule and encourages subscribers to purchase tickets.

### `game_email.html`

Sent shortly before each home game as a reminder. Highlights the upcoming matchup and event details and provides a link to purchase tickets.

## Technical Features

* Responsive layouts using CSS media queries
* Table-based structure for email-client compatibility
* Inline CSS for reliable rendering
* Outlook-specific compatibility styles
* Mobile-specific typography and spacing
* Responsive images
* Fallback fonts for email clients that do not support web fonts
* ESP-compatible unsubscribe functionality
* Branded calls-to-action and external links
